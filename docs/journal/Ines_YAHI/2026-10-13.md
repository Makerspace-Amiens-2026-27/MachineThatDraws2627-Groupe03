# 2026-10-13 : Analyse des codes existants et préparation du développement


**Séance :** planifiée · **Durée :** 2 h

## fait

Effectuer des recherches sur le code informatique nécessaire à la réalisation du projet.
Rechercher et analyser les codes réalisés par les étudiants de l'année précédente.
Étudier le fonctionnement du code existant afin de comprendre son organisation et de pouvoir m'en inspirer pour mon projet.
Mettre en ligne l'ensemble de mon journal personnel.

## Pourquoi

Pour identifier les outils et les langages de programmation nécessaires au projet.
Pour découvrir les solutions utilisées par les étudiants des années précédentes.
Pour comprendre le fonctionnement des programmes existants et éviter de repartir de zéro.
Pour pouvoir m'appuyer sur les travaux précédents afin de développer mon propre programme.

## Reste à faire

Approfondir l'analyse du code des années précédentes.
Identifier les parties du code qui peuvent être réutilisées ou adaptées.
Déterminer les modifications nécessaires pour répondre aux besoins de mon projet.
Commencer à élaborer et à tester mon propre code informatique.
